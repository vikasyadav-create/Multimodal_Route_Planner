Dijkstra's algorithm

Finds the shortest path from a source node to every reachable node in a graph with non-negative edge weights, by repeatedly visiting the closest unvisited node and relaxing its outgoing edges.

Time complexityO((V + E) log V)
Space complexityO(V + E)

V = stations, E = connections. The log V factor comes from the binary min-heap priority queue.
